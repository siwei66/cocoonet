The execution hierarchy should remain:

```text
parent → model/unit task → execution attempt
```

The filesystem hierarchy should intentionally compress it:

- Root working directory already represents one parent, so no root `parent_<id>/`.
- Each worker may serve multiple parents, so workers retain `results/parent_<id>/`.
- Each worker has only its own attempt for a parent/model.
- The root publishes only the selected attempt’s bundle.
- Therefore, neither root nor worker needs a final `attempt_<id>/` layer.
- Attempt identity remains in metadata, execution state, messages, and failure provenance.
