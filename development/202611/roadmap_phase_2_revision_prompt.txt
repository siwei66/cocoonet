Other requirements:
- Prefer human-readable formats like csv and txt for small files like single logs, schedules, configurations etc.
- For dictionary-like information, store keys as the first column and values as second column.
- For 2-dimensional tables, store identifiers as the first columns and other attributes as the later columns.
- For texts, store as text files, you can determine whether to use `.log` thematic extension or `.txt` common extension.

ISSUE 5:

Issue 5 is not a real issue but additional clarification of the public APIs to execute the cocoonet model evaluation pipeline for the users.

I make the additional clarifications for the interpretation of working process of cocoonet. They are designed in the later phases, but I clarify them here so that you can understand the demand for the persistency steps clearly without misinterpretation.

The expected public API for cocoonet root node usage is:
```text
# Evaluation experiment configuration
experiment_data = data_template(save_path, input_type='path')  # save_path is optional

# After filling the template
experiment = Experiment(data_entry=experiment_data, input_type='path', validation_method='5-fold')
# Or
experiment = Experiment(data_entry_path=save_path, input_type='path', validation_method='5-fold')

# Or if the input_type is data values themselves
experiment_data = data_template(save_path, input_type='value')
# Then
experiment = Experiment(data_entry=experiment_data, input_type='value', validation_method='5-fold')
# Or
experiment = Experiment(data_entry_path=save_path, input_type='value', validation_method='5-fold')


# Evaluation pipeline
evaluation = Evaluation(experiment)
evaluation.add_model(model, model_label, hyperparameters, training_parameters)
# Or
evaluation.add_model(model_path, model_label, hyperparameters, training_parameters)

# Or
evaluation = Evaluation(
    on=experiment,
    model_with_params=[
        {model_label: ..., model: ..., model_path: ..., hyperparameters: ..., training_parameters: ...},  # Provide either model or model path only
        ...
    ]
)

evaluation.ls_model(id, label, class_name, has_hyperparameter, has_training_parameter, exact_match=False, verbose=True)
evaluation.rm_model(id, label, class_name, has_hyperparameter, has_training_parameter, exact_match=False, verbose=True)

evaluation.add_worker(...)
evaluation.ls_worker(...)
evaluation.rm_worker(...)

# Execute on the root node dir work_dir as the working directory for this parent task
evaluation.run(work_dir, n_parallel=-1, resume=True, preflight_coverage=0.01, progress=True) # -1 means use maximum evaluation pipeline level parallelization on the worker nodes
```

As described above, data persistency is executed in most cases automatically without explicit public APIs to save the files, because cocoonet is a file-based pipeline itself.
