5. How should singular and bulk mutations share validation logic?

6. What is the scope of model-ID non-reuse after copying?

Clarification: ordinary copies have independent registries and preserve the same next-ID counter. Consequently, two copies can assign the same next numeric ID to different prospective models.

Example:

```text

original.add_model(A) -> model 2

```

This is valid if `model_id` is scoped to the eventual parent, but invalid if “persistent scope” means the shared root directory across every copied configuration.

Recommendation: explicitly define model IDs as unique and non-reused within one prospective computation lineage as committed to one parent—not globally across independently diverged copies. Different future parents may use the same numeric model ID. Phase 15 should prevent uncoordinated simultaneous control of the same persisted execution.
